# Fase blanda — dias 1 a 3 post-operatorio

Si el cirujano da otras instrucciones, **prevalecen las suyas**.

Objetivo: digestion suave, proteina facil, **evitar estreñimiento** (no forzar), hidratacion.

## Capsulas

Colageno manana · Multicentrum · Omega 3 en comida · Whey si comes poco · Agua a sorbos.

## Menu tipo (repetir / rotar estos 3 dias)

| Hora | Que |
|------|-----|
| **08:00** | Yogur griego o proteinas 125 g + platano maduro (poco) **o** manzana compota/rallada. Cafe suave si te dejan |
| **11:00** | Whey medio scoop en agua **o** yogur + kiwi |
| **14:00** | **1/2–1 crema brik** tibia (micro) + huevo revuelto vitro **o** 2–3 lonchas pavo. 1 rebanada pan si tolera |
| **17:00** | Yogur + pera/kiwi **o** whey **o** yogur + **poca** fruta cong. (cuenta como 1 de las 8–10 tomas) |
| **21:00** | Pescado blanco fresco vitro con tapa + calabacin/zanahoria micro **o** crema brik + queso 0% |

## OK / evitar

**OK:** arroz micro poca cantidad · tortilla solo huevo · atun natural con yogur · gazpacho suave dia 2–3.  
**Evitar:** legumbres, col, cebolla cruda mucha, fritos, picante, alcohol, ensaladas muy fibrosas, forzar el baño.
