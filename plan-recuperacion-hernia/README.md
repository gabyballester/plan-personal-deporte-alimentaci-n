# Plan recuperacion hernia inguinal (sept 2026)

Operacion en ~2 dias. **Sin deporte** estas ~2 semanas. Objetivo: cicatrizacion, proteina alta, antiestreñimiento, platos suaves y frescos.

**Cocina:** solo **microondas** y **vitroceramica** (sin airfryer, horno ni Thermomix).  
**Congelador:** ~1 cajon ? solo tus **4 sobres fruta cong.** (? 8–10 tomas). Resto: nevera + lata + brik + micro.

**Comensales:** 1 persona. **Compra:** Mercadona. Nevera de partida: vacia.
